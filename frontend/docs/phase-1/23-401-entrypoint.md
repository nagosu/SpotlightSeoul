# [P1-HTTP-04] 401 공통 처리 진입점 만들기(Phase 1 최소)

## 작업(What)

- 401(인증 실패)을 “각 화면에서 제각각 처리”하지 않도록, 공통 처리 진입점을 마련합니다.
- Phase 3에서 로그인/복귀 UX를 완성하되, Phase 1에서는 **기술적 처리 루트**를 먼저 준비합니다.

## 산출물(Deliverables)

- 401 감지 시 실행되는 공통 핸들러(예: 토큰 무효화/로그인 유도 이벤트 트리거)

## 완료 기준(DoD)

- 401이 발생했을 때 공통 처리 경로가 존재하며, 화면이 임의로 중복 처리하지 않아도 됩니다.

## 검증(Verification)

- 보호 API(예: 북마크/좋아요 토글)를 토큰 없이 호출해 401 분기 및 공통 처리 루트가 동작하는지 확인합니다.
