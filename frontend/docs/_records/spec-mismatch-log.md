# Spec Mismatch Log (OpenAPI ↔ 실제 서버 동작 불일치 기록)

> 목적: OpenAPI를 “단일 진실 원천”으로 두되, 실제 서버가 다르게 동작하는 경우를 기록해
> 프론트 임시 대응(워크어라운드)이 누적되더라도 이유/범위를 추적 가능하게 만듭니다.

## 기록 원칙

- “스펙이 틀린 건지”, “서버가 틀린 건지” 판단이 애매하면 **확인이 필요합니다**로 남기고,
  재현 절차/로그를 우선 기록합니다.
- 프론트에서 임시 대응을 넣었다면, 반드시 “조건/범위/제거 조건”을 명시합니다.
